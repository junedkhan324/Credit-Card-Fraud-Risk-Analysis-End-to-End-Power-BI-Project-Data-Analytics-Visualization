## 🚀 Project Highlights
# 💳 Credit Card Fraud Risk Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing and monitoring credit card fraud transactions using an interactive Power BI dashboard. The dashboard helps identify fraud patterns, transaction risks, geographical fraud distribution, and monthly fraud trends to support better fraud detection and business decision-making.

The dataset was cleaned and transformed using **Power Query**, and the dashboard was developed in **Power BI** for data visualization and analysis.

---

# 🚀 Key Objectives
- Identify high-risk fraudulent transactions
- Analyze fraud transaction trends by month
- Detect the most common fraud types
- Compare fraud risk distribution
- Monitor fraud transaction amounts across categories and states
- Build an interactive dashboard for business insights

---

# 🛠 Tools & Technologies Used
- **Power BI**
- **Power Query** (Data Cleaning & Transformation)
- **DAX**
- **Excel / CSV Dataset**

# 📊 Dashboard Features

## 🔹 KPI Cards
The dashboard displays important fraud metrics:
- Fraud Rate %
- Total Fraudulent Transactions
- Critical Risk Transactions
- Total Fraud Transaction Amount
- Top Fraud Type

---

## 🔹 Fraud Type Analysis
Analyzed fraud transaction amounts across different fraud categories:
- Card Not Present
- Card Skimming
- Identity Theft
- Account Takeover
- Phishing

Transaction categories included:
- Apparel
- E-commerce
- Electronics
- Food Delivery
- Groceries
- Transportation

---

## 🔹 Fraud Risk Distribution
Fraud transactions were classified into:
- Low Risk
- Medium Risk
- High Risk
- Critical Risk

This helps identify which risk category contributes most to fraudulent activity.

---

## 🔹 State-wise Fraud Analysis
Analyzed fraudulent transactions across multiple states to identify regions with higher fraud activity.

Top affected states include:
- Maharashtra
- Karnataka
- Rajasthan
- West Bengal
- Uttar Pradesh

---

## 🔹 Monthly Fraud Trend Analysis
Tracked fraud transactions month-by-month to identify:
- Seasonal fraud spikes
- Trend patterns
- High-risk periods

---

# 🧹 Data Cleaning Using Power Query
The dataset was cleaned and transformed using Power Query by:
- Removing null and duplicate values
- Standardizing column names
- Changing data types
- Handling missing values
- Filtering invalid records
- Creating calculated columns for analysis

---

# 📈 Key Insights
- **Card Not Present** fraud emerged as the most common fraud type.
- Medium and Low-risk transactions contributed the largest fraud share.
- Certain states showed consistently higher fraud activity.
- Fraud transactions peaked during specific months indicating trend-based risk patterns.
- E-commerce and Electronics categories showed higher fraud transaction amounts.
